🌳 树结构相关参数:
  1. 最大深度 (max_depth=7):
     - 控制树的复杂度，值越大树越深
     - 影响: 更深的树可以学习更复杂的模式，但容易过拟合

  2. 学习率 (learning_rate=0.2):
     - 控制每棵树的贡献权重
     - 影响: 值越小需要更多树，但可能获得更好的泛化能力

🎯 正则化参数:
  3. L2正则化 (reg_lambda=0.0):
     - 在叶子权重计算中惩罚大的权重值
     - 影响: w_j = -∑g_i / (∑h_i + λ)，λ越大叶子权重越小

  4. Gamma (gamma=0.0):
     - 控制分裂的最小增益阈值
     - 影响: Gain > γ 才进行分裂，γ越大树越简单

  5. 最小叶子权重 (min_child_weight=7):
     - 控制叶子节点所需的最小样本权重和
     - 影响: 防止创建样本数过少的叶子节点

🔄 采样参数:
  6. 样本采样 (subsample=1.0):
     - 每棵树随机采样的样本比例
     - 影响: 增强模型的随机性和泛化能力

  7. 特征采样 (colsample_bytree=0.5):
     - 每棵树随机采样的特征比例
     - 影响: 增强特征选择的多样性

💡 XGBoost 核心算法原理:
  节点分裂增益公式:
    Gain = 1/2 [G_L²/(H_L+λ) + G_R²/(H_R+λ) - (G_L+G_R)²/(H_L+H_R+λ)] - γ
  叶子节点权重公式:
    w_j* = - (∑g_i) / (∑h_i + λ)
  其中: g_i = 一阶梯度, h_i = 二阶梯度, λ = L2正则化系数
